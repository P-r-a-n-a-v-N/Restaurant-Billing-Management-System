# Restaurant-Billing-Management-System
This project is a complete restaurant billing and management application built with Python and MySQL, designed for small and medium restaurants that still rely on manual order-taking and paper bills.
It digitizes everything from showing the menu and taking orders to generating bills and viewing sales reports, so staff can work faster with fewer mistakes.
With this system, employees can log in, manage an employee database, and see daily sales directly from the terminal. 
Customers can view a well-structured menu (starters, main course, desserts, beverages), place orders by item code, and get an automatically calculated bill with quantities and totals stored in a SalesReport table.
There is also a simple customer membership and points feature, which can reward frequent visitors with vouchers and make the project feel closer to a real-world restaurant workflow.
If you are interested in how to combine Python, MySQL, and basic console UI to build an end-to-end backend for a restaurant, this project is a great codebase to explore and extend—whether you want to add GST/discount logic, table-wise orders, or a GUI/web front end on top of the existing logic.
